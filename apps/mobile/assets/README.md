# App Assets

Lege hier deine App-Assets ab:

| Datei | Größe | Beschreibung |
|-------|-------|--------------|
| `icon.png` | 1024×1024 | App Icon (iOS & Android) |
| `splash.png` | 1284×2778 | Splash Screen |
| `adaptive-icon.png` | 1024×1024 | Android Adaptive Icon (Vordergrund) |
| `notification-icon.png` | 96×96 | Android Notification Icon (weiß auf transparentem Hintergrund) |
| `favicon.png` | 48×48 | Web Favicon |

## Hinweise

- Alle Bilder als PNG
- Icon: quadratisch, kein Rand (App Store beschneidet Ecken selbst)
- Splash: weiß oder in deiner Brand-Farbe (#1e3a5f empfohlen)
- notification-icon: nur weißer Vordergrund (Android-Guideline)

## Generierung

Online-Tools:
- https://appicon.co — generiert alle Größen aus einem 1024×1024 Bild
- https://makeappicon.com — alternativ
